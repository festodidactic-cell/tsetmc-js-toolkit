# Contributing to TSETMC JS Toolkit

Thank you for your interest in contributing to TSETMC JS Toolkit.

This project aims to provide lightweight and reusable JavaScript utilities for TSETMC market screening, data processing, and financial analysis workflows.

## How to Contribute

### Reporting Issues

If you find a bug, unexpected behavior, or have a feature suggestion:

1. Check existing issues.
2. Create a new issue with:
   - Clear description
   - Expected behavior
   - Example data or screenshots when applicable

## Adding New Filters

When adding a new screening module:

- Keep the code lightweight.
- Avoid unnecessary dependencies.
- Use clear variable names.
- Include comments explaining the logic.
- Add examples when possible.

## Pull Requests

Before submitting a pull request:

1. Explain the purpose of the change.
2. Describe testing performed.
3. Keep commits focused and understandable.

## Code Style

Preferred:

- JavaScript ES5/ES6 compatible syntax
- Modular functions
- Simple readable logic
- Minimal external dependencies

Thank you for helping improve this project.
